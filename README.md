# SpaceClose
SpaceClose adds close buttons to fullscreen app previews in Mission Control, so you can close apps directly from the Spaces bar. Save prompts are brought to the front when needed, while native macOS settings let you customize the app and enable launch at login.

**Accessibility permission required:** Enable SpaceClose in **System Settings → Privacy & Security → Accessibility**.

**Updating from another version?** Quit SpaceClose, select its old Accessibility entry, and remove it using the **−** button. Install and launch the new version, then grant permission again. If no new request appears, use **+** to add the installed SpaceClose app and enable its switch.
